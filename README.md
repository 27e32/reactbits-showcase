# React Bits 组件交互预览台

五个 React Bits 风格组件的可交互预览台 —— 单文件、零依赖、完全离线可用。

## 包含的组件

| 标签 | 组件 | 说明 |
| --- | --- | --- |
| 圆环轮播 | CircularCarousel | 3D 圆环图片轮播，内置十二月人像，支持上传本地图片 |
| 技术文字 | TechText | 字母在指针附近溶解为虚线矢量轮廓，可拖离基线 |
| 流光文字 | ShinyText | 金属高光带扫过文字，可调角度/宽度/光带数/辉光 |
| 结晶球 | CrystalizedBall | WebGL2 + GPGPU 粒子星云球，指针感应、点击搅散 |
| 丝绸光绘 | WeaveSilk | 镜像对称的发光丝线，按住鼠标拖动绘制 |

## 页面文件

| 文件 | 说明 |
| --- | --- |
| `index.html` | 五合一入口（原 `reactbits-all-in-one.html`），顶部标签栏切换，全部内容内联 |
| `circular-carousel-preview.html` | 圆环轮播（内置 12 张十二月主题人像） |
| `techtext-preview.html` | 技术文字 |
| `shinytext-preview.html` | 流光文字 |
| `crystalized-ball-preview.html` | 结晶球 |
| `weavesilk-preview.html` | 丝绸光绘 |

每个页面都是**自包含单文件**：双击即可打开，不需要服务器、不需要联网。

## 移动端

所有页面已适配手机：窄屏（≤820px）时右侧控制面板自动变为**底部抽屉**，默认收起只露一条标题行，点一下展开。

## 交互提示

- **圆环轮播**：横向拖拽或滚轮左右滚动，点击卡片聚焦，面板里可切换 5 种预设（圆柱 / 环绕 / 转轮 / 全景 / 螺旋上升），支持上传本地图片替换
- **技术文字**：把鼠标移到字母附近，字母会溶解成虚线轮廓，可以拖走
- **结晶球**：移动指针扰动粒子，点击可把星云搅散
- **丝绸光绘**：按住鼠标拖动绘制，轨迹按对称轴自动镜像复制；画上的丝线永久保留，按住面板里的「淡出」才渐隐

## 构建工具（tools/）

| 脚本 | 作用 |
| --- | --- |
| `build_all_in_one.py` | 把 5 个子页面内联合成五合一单文件 |
| `watch_and_rebuild.py` | 监视子页面改动，自动重建五合一 |
| `add_mobile_support.py` | 批量注入移动端适配（幂等，可重复执行） |
| `process_months.py` | 裁水印 / 压缩 / 编码十二月人像 |
| `embed_months.py` | 把图片 base64 内嵌进页面 |
| `make_carousel_test.js` | 生成无外链的测试副本，便于无头验证 |

根目录两个 `.bat` 是 Windows 下的便捷入口：`rebuild-all.bat` 手动重建一次，`watch-and-rebuild.bat` 常驻监视自动重建。

## 实现要点

- **零依赖**：五个组件均为原生 JS + Canvas / CSS 3D 实现，没有引用任何第三方库
- **完全离线**：图片以 base64 内嵌，页面运行时无任何外部请求
- **五合一的隔离方式**：几个子页面各自带有同名的 ID 与类名（`#panel`、`#stage`、`#controls` 等），直接合并会互相冲突，因此采用「iframe 隔离 + 内容内联」—— 每个组件跑在自己的 iframe 里互不干扰，但内容以字符串形式内嵌，最终仍然只有一个文件
- **iframe 内容转义注意点**：子页面含 `<script>` 标签，放进外层脚本字符串时会提前闭合外层脚本，处理方式是 `json.dumps()` 之后把 `</` 替换成 `<\/`
